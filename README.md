# QUANTUM CORE — 量子クリッカーゲーム

おしゃれなダークモードUIのWebクリッカーゲームです（HTML / CSS / JavaScript）。

## 主な機能
- **⚡ 量子コア・クリック**: コアをクリックしてポイントを獲得（フローティング演出・効果音付き）。
- **🛒 オートメーション・ショップ**: 稼いだポイントを消費して、1秒ごとに自動でポイントが増える施設やクリック強化アイテムを購入可能。
- **🎰 量子ルーレット（全6種抽選）**: 右側パネルのタブからいつでも切り替え可能。Canvas描画による滑らかな回転アニメーションとWeb Audio APIによる電子ティック音を搭載。
- **🎟️ 無料抽選チケットシステム**: 初期特典として1枚付与。さらにコアを50回クリックするごとに無料チケットを1枚獲得（チケットがない場合もポイントを消費して抽選可能）。
- **🔥 リアルタイム・フィーバーバフ**: 「30秒間 生産＆クリック2倍」「30秒間 クリック獲得5倍」「30秒間 自動生産3倍」当選時は左パネルにカウントダウン付きバフステータスが表示され、リアルタイムで獲得量がブーストされます。

## 遊び方
`index.html` をブラウザで直接開くか、ローカルサーバーを起動してアクセスしてください。

```bash
python3 -m http.server 8000
```
